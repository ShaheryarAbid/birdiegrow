# Integration Backlink Plan — Door-Access Partners
_July 28, 2026 · pairs with the new /integrations pages_

## The play
Each door-access partner runs a technology/ISV partner directory. Getting Birdie listed earns a **relevant, high-DR backlink** and an entity association that helps both classic SEO and AI-search citations. We now have a dedicated landing page per partner to point each listing at, which makes the ask concrete and the link more valuable.

**Proof it works:** getkisi.com (DR72) already links to Birdie — that's Kisi, a door partner. The other four are the same motion.

## Targets (priority order)

### 1. Kisi — DR ~72 · already linked ✅
Confirm the existing listing is current and points to `/integrations/kisi`. If it's only a modal/logo link, ask them to make it a standard link.
- Directory: https://www.getkisi.com/integrations

### 2. RemoteLock — high DR · ISV/Software Partner track
Strongest fit: they actively recruit software integrations and list them.
- Partners: https://remotelock.com/partners
- Software Partners: https://remotelock.com/software-partners/
- Become a partner: https://remotelock.com/become-a-partner/
- Directory article: https://support.remotelock.com/s/partner-integrations
- **Ask:** ISV / Software Partner listing → link to `/integrations/remotelock`.

### 3. ProDataKey (PDK) — Open API / technology partner
- Integrations: https://www.prodatakey.com/integrations
- Open API / partner: https://www.prodatakey.com/become-a-partner/api
- **Ask:** technology-integration listing → link to `/integrations/pdk`.

### 4. Avigilon Alta (Motorola) — very high DR, harder gate
Motorola's Partner Advantage program is installer/reseller-heavy, but the integrations page lists technology partners.
- Integrations: https://www.avigilon.com/integrations
- Partners: https://www.avigilon.com/partners
- **Ask:** technology-partner / "works with Alta" listing → link to `/integrations/avigilon-alta`. Expect a longer process.

### 5. UniFi Access (Ubiquiti) — no formal ISV marketplace
Ubiquiti doesn't run a third-party integration directory, so a clean backlink is unlikely. Lower priority for links — the `/integrations/unifi-access` page still captures the "UniFi Access golf simulator" search demand on its own. Optional: a Ubiquiti Community post documenting the integration.
